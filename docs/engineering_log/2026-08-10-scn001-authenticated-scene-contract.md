# SCN-001 authenticated structural scene contract

- **Goal:** establish the deny-by-default receiver boundary needed before a real interactive Windows scene producer can be connected.
- **Master-plan phase / gate:** M2, SCN-001; this is source/unit progress only and does not pass or promote the gate.
- **Subsystem ownership:** shared contract between the guest-local Glove scene producer and Field channel identity; no authority is transferred.
- **Files changed:** `src/fieldChannel.ts`, `src/fieldSceneObservation.ts`, `src/fieldSceneChannel.ts`, `tests/fieldSceneChannel.test.ts`, `package.json`, .NET channel enum/test, Field test/threat/failure/traceability docs, and the Level 4 addendum.
- **Identity/generation and policy impact:** scene receipt now requires exact Field generation, boot, agent, Windows session, key, direction, expiry, and durable sequence. It cannot create or expand policy, consent, recording, execution, or Field administration.
- **Parts & Pieces / donor patterns:** reused the existing authenticated envelope, durable replay guard, heartbeat, structural scene adapter, and scene schema. No donor repository evidence is claimed.
- **Questions and assumptions:** the configured Windows session ID is owner/Field-attestation input. The LocalSystem runtime is session 0 and therefore cannot be treated as the interactive UIA producer. A separate authenticated session-local producer/relay is still required.
- **Tests added or updated:** positive monotonic scene receipt; raw text/screenshot, wrong identity/type, overflow, replay, and timestamp-regression denial; shared .NET wire-name assertion.
- **Commands actually run:** focused Vitest scene/channel tests; TypeScript typecheck; .NET SDK 8.0.423 restore/build/test; repository/plan/Field/completion validators; full Field suite; full repository suite; isolated adversarial completion/live-attestation rerun; TypeScript build; Field and system pulses.
- **Results and evidence class:** source/unit only. Focused scene/channel tests passed 12/12. Typecheck and build passed. Repository, master-plan, Field-contract, and completion validators passed with zero integrity failures. Field suite passed 51/51 files and 263/263 assertions; Field and system pulses passed 1/1 each. .NET Release warnings-as-errors build passed with 0 warnings/errors and 84/84 tests passed. The aggregate repository run passed 691/694 assertions but three unrelated completion-security tests exceeded Vitest's 10-second limit under worker saturation and emitted two worker RPC timeouts; an isolated single-worker rerun with a 30-second bound passed both affected files, 86/86 assertions. No live Windows evidence was produced.
- **Assumptions and unvalidated areas:** no live producer, transport emission, UIA accuracy, cursor/modal collector, lock/Secure Desktop transition, long stream, restart/backpressure, or privacy acceptance evidence.
- **Security/privacy impact:** narrows transport to structural-only metadata, forbids screenshots and UI text, bounds resource use, and rejects all binding failures before state advances.
- **Field failure behavior:** wrong boot/session/generation/key/replay/overflow/stale data fails closed. Lock or Secure Desktop derives non-actionable state from the authenticated heartbeat. No input exists in this slice, so uncertain effects and emergency stop are unchanged.
- **Storage impact:** no immutable base, disposable overlay, personal state, or task disk is touched.
- **Rollback / disable path:** do not instantiate the receiver; remove the new message type. Existing channel and scene source contracts continue independently.
- **Next recommended slice:** implement and audit the session-local Glove scene producer plus authenticated bounded local relay, then rebuild the immutable base and collect SCN-001 live evidence before enabling input.
